# Resume bullets

## 中文

- 使用 Java 21、Spring Boot、Spring Security、MySQL 与 Redis 开发内部工单和知识管理系统，实现 JWT、Refresh Token Rotation、RBAC、资源级权限控制、请求追踪与审计日志。
- 实现工单评论、分配、状态流转和乐观锁，以及知识文章生命周期与安全文件上传下载；使用 Flyway 管理数据库版本，并通过事务保持业务变更与审计记录一致。
- 使用 Testcontainers 对真实 MySQL 8.4 / Redis 7.4 运行集成测试，并通过 Docker Compose 验证 Vue、Spring Boot、MySQL、Redis 和持久化文件存储的完整流程。

## English

- Built an internal ticket and knowledge management system with Java 21, Spring Boot, Spring Security, MySQL, and Redis, implementing JWT authentication, refresh-token rotation, RBAC, resource-level authorization, request tracing, and audit logs.
- Implemented ticket comments, assignment, state transitions, optimistic locking, article lifecycle management, and secure document upload/download; managed schema changes with Flyway and kept business writes and audit records in shared transactions.
- Tested against real MySQL 8.4 and Redis 7.4 containers with Testcontainers and verified the Vue, Spring Boot, database, session, and persistent file-storage flow through Docker Compose.
